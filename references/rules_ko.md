# 보고서·슬라이드 교정 규칙 레퍼런스

§1~§2는 `paper-proofread`의 공통 한국어 규칙을 업무 문서에 맞게 다듬은 것이고, §3~§6은 보고서·슬라이드 전용 규칙이다. 각 항목은 패턴 → 수정안 → 근거 순서다.

## 1. 표기 교정

### 1.1 빈출 맞춤법 오류

| 틀린 표기 | 바른 표기 | 비고 |
|-----------|-----------|------|
| 데이타 | 데이터 | 외래어 |
| 컨텐츠 | 콘텐츠 | 외래어 |
| 메세지 | 메시지 | 외래어 |
| 리더쉽 / 파트너쉽 | 리더십 / 파트너십 | 외래어 |
| 워크샵 | 워크숍 | 외래어 |
| 악세사리 / 악세스 | 액세서리 / 액세스 | 외래어 |
| 프레젠테이숀 / 프리젠테이션 | 프레젠테이션 | 외래어 |
| 스케쥴 | 스케줄 | 외래어 |
| 타겟 | 타깃 | 외래어 |
| 런칭 | 론칭 | 외래어 (브랜드 공식 표기면 유지) |
| 비지니스 | 비즈니스 | 외래어 |
| 솔루션 / 플랫폼 | (맞음) | — |
| 갯수 / 댓가 / 잇점 | 개수 / 대가 / 이점 | 사이시옷 오적용 |
| 몇일 | 며칠 | 맞춤법 |
| 할께요 / 할께 | 할게요 / 할게 | ㄹ게 |
| 되요 / 됬다 | 돼요 / 됐다 | 되어 → 돼 |
| 안되다 (불가) | 안 되다 | 부정 부사 '안'은 띄움. 단 '안되다(가엾다)'는 붙임 |
| 않되다 | 안 되다 | '않-'은 '-지 않다' |
| 금새 | 금세 | 금시에 |

| ~로서 / ~로써 혼동 | 자격 '로서', 수단 '로써' | 담당자로서, 대화로써 |
| 결제 / 결재 | 돈 지불 '결제', 상사 승인 '결재' | 업무 문서 빈출 |
| 지양 / 지향 | 피함 '지양', 향함 '지향' | 뜻 반대 |
| 재고 / 제고 | 다시 생각 '재고', 높임 '제고' | 효율 제고 |
| 반증 / 방증 | 반대 증거 '반증', 간접 증거 '방증' | — |
| 및 / 등 남발 | 필요한 곳만 | 🔵 |

### 1.2 띄어쓰기

**의존명사 (띄움)**: `할 수`, `한 바`, `한 것`, `할 때`, `하는 데(장소·일)`, `할 뿐`, `한 지(시간)`, `할 만큼`, `할 듯`, `할 터`

**단위명사**: 숫자와 함께 쓰면 붙여 쓸 수 있다. `3개`, `10명`, `5회`, `2026년`, `3개월` — 문서 안에서 통일만 확인.

**접사 (붙임)**: `제1차`, `총인원`. 관형사 '약'은 띄움: `약 30%`. 기간의 '간'은 붙임: `3일간`, `두 달간`. 단 사이·관계의 '간'은 띄움: `부서 간 협업`, `지역 간 격차`.

**보조용언**: 띄움이 원칙, 붙임도 허용 → 문서 안에서 통일 여부만 본다. `검토해 보다/검토해보다`, `지원해 주다/지원해주다`.

**업무 문서 빈출**:
| 틀림 | 바름 |
|------|------|
| 상반기중 | 상반기 중 |
| 이번주 / 다음달 | 이번 주 / 다음 달 |
| 그동안 / 그때 / 이때 | 붙임 (한 단어) |
| 첫번째 | 첫 번째 |
| 기간동안 | 기간 동안 |
| 운영방안 / 개선방안 | 운영 방안 / 개선 방안 (제목에서는 붙임도 흔함 → 통일만) |
| 추진계획 | 추진 계획 (위와 같음) |

> 제목·표 머리의 명사 나열(`사업추진계획`)은 붙여 쓰는 관행이 넓다. 본문과 제목 간 차이는 지적하지 않고, 같은 층위 안 혼용만 🔵로 본다.

| 괄호가 문장 일부면 마침표는 괄호 뒤 | ~했다(표 3 참조). |

## 2. 문장 교열

### 2.1 번역투 (🟡)

| 패턴 | 교정안 |
|------|--------|
| ~에 있어서 | ~에서 / ~에게 |
| ~하는 것이 가능하다 | ~할 수 있다 |
| ~하는 것이 필요하다 | ~해야 한다 |
| ~를 통해(서) 남발 | ~로 / ~에서 / 문장 재구성 |
| ~에 대한 ~에 대한 | 하나를 다른 말로 |
| ~의 ~의 ~의 | 관형절이나 조사 바꾸기 |
| ~에 의해 ~되다 | 능동문 |
| ~를 가지다 (회의를 가지다) | 회의를 열다 / 하다 |
| ~로부터 | ~에서 / ~에게서 |
| 가장 ~중의 하나 | ~ 가운데 하나 / 손꼽히는 |

### 2.2 이중피동 (🔴)

`되어지다` → `되다`, `보여지다` → `보이다`, `잊혀지다` → `잊히다`, `쓰여지다` → `쓰이다`, `개선되어짐` → `개선됨`

### 2.3 업무 문서 군더더기 (🟡)

| 패턴 | 교정안 |
|------|--------|
| ~하도록 하겠습니다 | ~하겠습니다 |
| ~할 수 있도록 하는 | ~하는 / ~을 위한 |
| 진행하다 남발 (교육을 진행) | 교육하다 / 교육을 운영하다 |
| ~적인 부분 / ~쪽으로 | 삭제·구체화 |
| ~하는 것으로 확인됨 | ~함을 확인 / ~함 |
| ~관련하여 / 관련 남발 | 구체 조사로 |
| 약 30% 정도 / 대략 ~가량 | 약 30% |
| 미리 예약 / 사전 예약 신청 | 예약 / 사전 신청 |
| 가장 최고 / 가장 최적 | 최고 / 최적 |
| 과반수 이상 | 과반수 / 절반 이상 |
| 기간 동안 내내 | 기간 동안 |

### 2.4 호응·조사

- 주어-서술어: 긴 문장에서 주어가 바뀌는지 확인 (`본 사업은 ~를 목표로 하며 참여자는 ~한다` → 주어 두 개 확인)
- `~과/와 ~을` 병렬에서 동사 하나가 두 목적어에 다 맞는지 (`역량과 만족도를 향상` → `역량을 높이고 만족도를 향상`)
- `~에/에게`: 사람·동물엔 `에게`, 기관·사물엔 `에` (`학교에게` ✕)

## 3. 문체 통일

### 3.1 개조식 기본

| 종결 방식 | 예 | 쓰임 |
|-----------|----|------|
| 명사 종결 | 신규 고객 30% 증가 | 슬라이드, 요약 |
| 명사형 어미 `-음/-ㅁ` | 신규 고객이 30% 증가함 | 보고서 개조식 |
| `-기` | 매주 결과 공유하기 | 실행 목록, 체크리스트 |
| 예정형 | 12월 중 시행 예정 | 계획 |

같은 목록·같은 층위에서 섞이면 🟡. 예정형은 다른 형태와 섞여도 의미상 필요하면 허용.

### 3.2 개조식 오류

| 오류 | 교정 | 사유 |
|------|------|------|
| 증가됨 / 감소됨 / 상승됨 | 증가함 / 감소함 / 상승함 | '증가되다' 등은 사전 등재어라 오류는 아님. 저절로 늘어난 뜻이면 '-하다'가 간결 → 🔵. 한 문서 안 혼용은 🟡 |
| ~할 것임 / ~하는 것임 남발 | ~할 예정 / ~함 | 군더더기 |
| 문장 끝 `~하였음.` + `~합니다.` 혼용 | 하나로 | 🔴 |

### 3.3 서술 문체

- 본문에서 `합니다체`와 `한다체` 혼용 🔴. 다수 쪽으로 통일 권고.
- 외부용(고객·학부모·기관) 문서는 `합니다체`가 기본. 해요체는 친근한 안내문에서만.
- 경어 과잉: `말씀하신 내용이십니다`, `주문하신 커피 나오셨습니다` 형 사물 높임 🟡.
- 공문: `~하시기 바랍니다`, `~를 알려 드립니다`(띄움 원칙). `~해 주시기 바랍니다` 통일.

## 4. 숫자·단위·용어

### 4.1 숫자 표기

| 항목 | 기준 |
|------|------|
| 천 단위 쉼표 | 네 자리 이상 `1,250` (표 안에서 통일) |
| 금액 | `1,500만 원`, `3억 2천만 원`. 표는 단위 머리에 `(단위: 백만 원)` 통일 |
| 원 띄어쓰기 | `만 원`, `100원` (숫자+원 붙임, 만·억 뒤 원은 띄움) |
| 퍼센트 vs 퍼센트포인트 | 비율끼리의 차이는 `%p` (23% → 28%는 5%p 상승) 🔴 |
| 소수 | 같은 표·같은 지표는 자릿수 통일 |
| 범위 | `10~20명` (뒤에만 단위) |
| 날짜·요일 | 요일이 붙어 있으면 실제 요일 확인. 2026-11-11은 수요일 🔴 |
| 시간 | `14:00` / `오후 2시` 통일 |

### 4.2 수치 대조

- 같은 지표가 두 곳 이상에 나오면 값·단위·기준 시점을 나란히 비교
- 표 합계, 비율 합(100%), 증감률 = (후-전)/전 계산 검산
- 증감 표현과 수치 방향 일치 (`감소`인데 값이 늘어난 경우 🔴)
- 반올림으로 생기는 0.1 차이는 🔵 주석만

### 4.3 용어

- 고유명사: 문서가 정한 공식 표기 우선 (브랜드 영문/국문, 띄어쓰기)
- 약어: 외부용 문서는 첫 등장에 풀이 `KPI(핵심성과지표)`. 내부용은 통일만
- 같은 대상 다른 이름(`참가자`/`참여자`/`수강생`) 🟡 — 하나로 통일안 제시

## 5. 보고서 구조

| 항목 | 기준 |
|------|------|
| 두괄식 | 섹션 첫 문단·첫 불릿에 요지 |
| 번호 체계 | 예: `1. → 가. → 1) → 가) → (1) → (가)` 층위 순서 일관, 번호 누락 없음 |
| 소제목 병렬 | 같은 층위 제목 형태 통일 (`현황 / 문제점 / 개선 방안` ↔ `현황 분석 / 문제가 무엇인가` ✕) |
| 표·그림 | 번호 순서, 제목 위치(표는 위, 그림은 아래 등) 통일, 본문 참조 |
| 출처 | 외부 데이터 표·그림 아래 `자료: 기관명(연도)` 형식 통일 |
| 공문 | 제목·수신·관련 근거 번호, 붙임 목록, 본문 끝 `끝.` 또는 붙임 뒤 `끝.` |
| 회의록 | 일시·장소·참석자·안건·결정·담당·기한 |

## 6. 슬라이드

| 항목 | 기준 | 심각도 |
|------|------|--------|
| 제목 길이 | 한 줄(약 25자) 안 | 🔵 |
| 메시지형 제목 | 주제어 제목은 한 문장 요지 대안 제시 | 🔵 |
| 제목-본문 일치 | 제목이 말하는 것을 본문이 뒷받침 | 🟡 |
| 불릿 수 | 한 장 7개 이하 | 🔵 |
| 들여쓰기 | 2단계까지 | 🟡 |
| 불릿 길이 | 40자 안, 한 불릿 한 메시지 | 🔵 |
| 불릿 병렬 | 같은 층위는 같은 문법 형태 | 🟡 |
| 마침표 | 불릿 끝 마침표 유무 통일 | 🔵 |
| 차트 | 제목·단위·축 이름·범례 명칭이 본문과 일치 | 🟡 |
| 출처 | 외부 수치·인용·이미지에 출처 | 🟡 |
| 목차 | 목차 항목 = 실제 섹션 구분 슬라이드 제목 | 🔴 |
| 표지·마무리 | 날짜·발표자·소속 표기가 문서 다른 곳과 일치 | 🔴 |
| 노트 | 발표자 노트도 맞춤법·수치 점검 대상 | — |

수정안은 원문보다 길게 만들지 않는다. 화면 공간이 정해져 있기 때문이다.

## 7. 심각도 기준

| 심각도 | 기준 |
|--------|------|
| 🔴 error | 규범 위반, 수치·날짜·목차 불일치, 서술 종결어미 혼용, %·%p 혼동 |
| 🟡 suggest | 번역투, 군더더기, 불릿 문체 혼용, 용어 흔들림, 단위·출처 누락 |
| 🔵 style | 메시지형 제목, 밀도·길이, 반올림 주석, 허용 표기 통일 |
